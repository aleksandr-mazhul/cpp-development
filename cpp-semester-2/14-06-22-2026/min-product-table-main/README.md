# Мини-таблица товаров (учёт на складе)

## Цель

Написать консольную программу, которая читает список товаров из **CSV-файла**, вычисляет показатели склада, выводит сводку на экран и сохраняет ту же сводку в текстовый отчёт.

## Входные данные

Товары хранятся в файле `products.csv` в каталоге проекта.

### Формат файла

- Кодировка: UTF-8 (для этой задачи достаточно имён товаров в ASCII).
- Первая строка — **заголовок** (названия столбцов), это не строка с товаром.
- Каждая следующая строка — один товар: три поля, разделённые запятой; запятых внутри названия быть не должно.

Пример:

```csv
Product,Price,Quantity
Mouse,1200,5
Keyboard,3500,2
Monitor,15000,1
```

| Столбец    | Тип     | Смысл                                           |
|------------|---------|-------------------------------------------------|
| `Product`  | строка  | Название товара                                 |
| `Price`    | целое   | Цена за единицу (одна валюта для всех позиций)  |
| `Quantity` | целое   | Количество на складе (неотрицательное)          |

Для проверки можно добавить в файл больше строк. Программа должна корректно работать с **любым числом** строк данных после заголовка.

## Обязательная функциональность

### 1. Чтение CSV

- Открыть `products.csv`.
- Пропустить строку заголовка.
- Разобрать каждую строку данных: название, цена за единицу, количество.
- Обработать типичные ошибки (файл не найден, пустой файл, неверное число столбцов) с понятным сообщением.

Рекомендуемый подход: читать файл построчно (`std::getline`), разбивать строку по запятой (`std::getline` с разделителем `','` через `std::istringstream`).

### 2. Стоимость позиции (по каждому товару)

Для каждого товара вычислить:

**стоимость позиции = Price × Quantity**

Использовать тип, достаточный для умножения без переполнения (например, `long long`).

### 3. Общая стоимость склада

Сложить стоимости позиций **всех** товаров.

### 4. Самый дорогой товар

Найти товар с **наибольшей стоимостью позиции** (это не обязательно товар с самой высокой ценой за единицу).

При равенстве значений можно вывести любой из подходящих товаров.

### 5. Вывод в консоль

Печатать сообщения **на английском**, например:

- блок со списком каждого товара: цена, количество, стоимость позиции;
- общая стоимость склада;
- самый дорогой товар (название и его стоимость позиции).

### 6. Файл отчёта (обязательно)

Сохранить ту же информацию в `report.txt` в удобочитаемом виде (заголовки и те же числа, что и в консоли).

## Структура программы (рекомендации)

- `struct` (или `class`) для одного товара: название, цена, количество; по желанию — метод расчёта стоимости позиции.
- Функция загрузки товаров из CSV в `std::vector<Product>`.
- Функция записи отчёта в файл.
- `main`: загрузка → расчёты → вывод → сохранение отчёта.

Использовать **C++17** или новее (`std::ifstream`, `std::ofstream`, `std::vector`, `std::string`, исключения или проверки ошибок — на ваш выбор).

## Пример (эталонные значения)

Для трёх строк из примера выше:

| Товар    | Цена  | Кол-во | Стоимость позиции |
|----------|-------|--------|-------------------|
| Mouse    | 1200  | 5      | 6000              |
| Keyboard | 3500  | 2      | 7000              |
| Monitor  | 15000 | 1      | 15000             |

- **Общая стоимость склада:** 28000  
- **Самый дорогой товар:** Monitor (15000)

Фактический вывод программы должен соответствовать вашему реальному `products.csv`.

## Дополнительные задания

- Дополнительно выводить товар с **максимальной ценой за единицу** (может не совпадать с максимальной стоимостью позиции).
- Форматировать числа с разделителем тысяч в отчёте.
- Проверять, что цена и количество неотрицательны.
