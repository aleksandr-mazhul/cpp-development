# Система управления данными сотрудников

## Описание задачи

Система предназначена для работы с данными сотрудников, включая их хранение в бинарном формате, чтение, фильтрацию и вывод в текстовый формат.

### Основные компоненты системы

1. **Класс Employee**
   - Хранит информацию о сотруднике:
     - Имя (максимум 50 символов)
     - Возраст (от 18 до 100 лет)
     - Зарплата (неотрицательное значение)
     - Опыт работы (неотрицательное значение, не может превышать возраст - 18)
   - Методы для работы с данными:
     - Конструкторы (по умолчанию и с параметрами)
     - Геттеры для всех полей
     - Методы для бинарной записи/чтения
     - Метод для текстового вывода

2. **Класс EmployeesIO**
   - Обеспечивает ввод/вывод данных:
     - Запись тестовых данных в бинарный файл
     - Чтение данных из бинарного файла
     - Запись отфильтрованных данных в текстовый файл
   - Содержит константы для фильтрации:
     - Порог высокой зарплаты
     - Порог опыта работы
     - Порог молодого возраста
     - Максимальное количество сотрудников

3. **Функции фильтрации**
   - `filterHighSalary`: фильтр по высокой зарплате
   - `filterExperienced`: фильтр по опыту работы
   - `filterYoung`: фильтр по молодому возрасту
   - `filterEmployees`: общая функция фильтрации с предикатом

### Требования к реализации

1. **Валидация данных**
   - Проверка корректности всех входных данных
   - Выброс исключений при некорректных данных
   - Использование стандартных исключений

2. **Работа с файлами**
   - Бинарное хранение данных
   - Текстовый вывод для чтения
   - Обработка ошибок ввода/вывода

3. **Организация кода**
   - Разделение на заголовочные и реализационные файлы
   - Использование прототипов функций
   - Именованные константы в PascalCase
   - Обработка исключений в main

### Пример использования

```cpp
// Создание тестовых данных
EmployeeIO::writeToBinaryToFile("employees.dat");

// Чтение данных
Employee all[EmployeeIO::MaxEmployees];
int total = EmployeeIO::readFromBinaryFile("employees.dat", all, EmployeeIO::MaxEmployees);

// Фильтрация по опыту работы
Employee filtered[EmployeeIO::MaxEmployees];
int filteredCount = filterEmployees(all, total, filtered, filterExperienced);

// Запись результатов
EmployeeIO::writeToTextFile("filtered_employees.txt", filtered, filteredCount);
```

### Обработка ошибок

Система обрабатывает следующие типы ошибок:
1. Некорректные входные данные (std::invalid_argument)
2. Ошибки ввода/вывода (std::runtime_error)
3. Неизвестные ошибки (std::exception)

### Формат файлов

1. **Бинарный файл (employees.dat)**
   - Последовательность записей Employee в бинарном формате
   - Каждая запись имеет фиксированный размер

2. **Текстовый файл (filtered_employees.txt)**
   - Каждая запись в формате:
     ```
     Name: [имя], Age: [возраст], Salary: [зарплата], Experience: [опыт]
     ```
