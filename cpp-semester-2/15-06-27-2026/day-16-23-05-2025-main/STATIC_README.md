# Статические поля и константы в C++

## Статические поля (static fields)

### Общие характеристики
- Принадлежат классу, а не объектам класса
- Существуют в единственном экземпляре для всего класса
- Разделяются между всеми объектами класса
- Инициализируются один раз при загрузке программы

### Пример использования
```cpp
class Counter {
private:
    static int totalCount;  // статическое поле
    int localCount;

public:
    Counter() {
        localCount = 0;
        totalCount++;  // увеличиваем общий счетчик
    }
    
    static int getTotalCount() {
        return totalCount;  // доступ к статическому полю
    }
};

// Определение статического поля (в .cpp файле)
int Counter::totalCount = 0;
```

### Особенности
- Должны быть определены вне класса (в .cpp файле)
- Могут быть изменены во время выполнения программы
- Могут быть как публичными, так и приватными

## Статические константы (static const)

### Общие характеристики
- Как и статические поля, принадлежат классу
- Не могут быть изменены после инициализации
- Могут быть инициализированы прямо в классе (для целочисленных типов)
- Для других типов требуют определения вне класса

### Примеры
```cpp
class EmployeeIO {
public:
    // Целочисленные константы можно инициализировать в классе
    static const int MaxEmployees = 100;
    static const int SampleEmployeesCount = 5;
    
    // Для double нужно определение вне класса
    static const double HighSalaryThreshold;
};

// Определение в .cpp файле
const double EmployeeIO::HighSalaryThreshold = 1000.0;
```

### Особенности
- Могут быть инициализированы в классе только если:
  - Это целочисленный тип (int, char, bool)
  - Это перечисление (enum)
  - Это указатель или ссылка
- Для других типов (double, string и т.д.) требуется определение вне класса
- Не могут быть изменены после инициализации

## Сравнение использования

### Статические поля
Используются для хранения данных, которые:
- Должны быть общими для всех объектов
- Могут изменяться во время выполнения

Примеры использования:
- Счетчики
- Кэши
- Общие ресурсы

### Статические константы
Используются для:
- Конфигурационных параметров
- Пороговых значений
- Размеров массивов
- Других неизменяемых значений

## Пример из проекта

```cpp
class EmployeeIO {
public:
    // Статические константы для конфигурации
    static const int SampleEmployeesCount = 5;
    static const int MaxEmployees = 100;
    static const double HighSalaryThreshold = 1000.0;
    static const int ExperiencedThreshold = 5;
    static const int YoungAgeThreshold = 30;
    
    // Статические методы для работы с данными
    static void writeToBinary(std::ostream& os);
    static int readFromBinary(std::istream& is, Employee* buffer, int maxCount);
    static void writeToText(std::ostream& os, const Employee* employees, int count);
};
```

### Преимущества использования статических констант
1. Централизованное управление значениями
2. Легкость изменения при необходимости
3. Избежание "магических чисел" в коде
4. Улучшенная читаемость и поддерживаемость кода

### Применение в проекте
Статические константы используются для:
1. Определения размеров массивов (`MaxEmployees`)
2. Задания пороговых значений для фильтрации
3. Хранения конфигурационных параметров 

## Сравнение типов констант в C++

### Обычные константы (const)
```cpp
class Example {
private:
    const int value = 42;  // обычная константа
};
```
- Принадлежат конкретному объекту класса
- Создаются для каждого объекта отдельно
- Могут быть инициализированы в конструкторе
- Занимают память для каждого объекта

### Статические константы (static const)
```cpp
class Example {
public:
    static const int value = 42;  // статическая константа
};
```
- Принадлежат классу, а не объектам
- Существуют в единственном экземпляре
- Разделяются между всеми объектами
- Экономят память (хранятся один раз)

### Constexpr константы
```cpp
class Example {
public:
    static constexpr int value = 42;  // constexpr константа
    constexpr int calculate(int x) { return x * 2; }
};
```
- Вычисляются на этапе компиляции
- Могут использоваться в контекстах, требующих констант времени компиляции
- Могут быть функциями, которые вычисляют значения на этапе компиляции
- Обеспечивают лучшую производительность

### Сравнительная таблица

| Характеристика | const | static const | constexpr |
|----------------|-------|--------------|-----------|
| Время вычисления | Runtime | Runtime | Compile-time |
| Принадлежность | Объекту | Классу | Классу/Глобальная |
| Память | Для каждого объекта | Один экземпляр | Один экземпляр |
| Инициализация | В конструкторе | При объявлении | При объявлении |
| Использование в шаблонах | Нет | Нет | Да |
| Использование в switch | Нет | Да (int) | Да |

### Примеры использования

```cpp
class Constants {
public:
    // Обычная константа
    const int instanceValue = 10;
    
    // Статическая константа
    static const int classValue = 20;
    
    // Constexpr константа
    static constexpr int compileTimeValue = 30;
    
    // Constexpr функция
    static constexpr int calculate(int x) {
        return x * 2;
    }
};

// Использование в switch
void example() {
    int value = 20;
    switch(value) {
        case Constants::classValue:      // OK
        case Constants::compileTimeValue: // OK
        case Constants::instanceValue:    // Error
            break;
    }
}

// Использование в шаблонах
template<int N>
struct Array {
    int data[N];
};

Array<Constants::compileTimeValue> arr1;  // OK
Array<Constants::classValue> arr2;        // Error
Array<Constants::instanceValue> arr3;     // Error
```

### Рекомендации по использованию

1. Используйте `const` для:
   - Значений, которые не должны меняться после инициализации объекта
   - Параметров функций, которые не должны изменяться внутри функции

2. Используйте `static const` для:
   - Общих для всех объектов значений
   - Конфигурационных параметров класса
   - Пороговых значений

3. Используйте `constexpr` для:
   - Значений, которые должны быть известны на этапе компиляции
   - Функций, которые могут быть вычислены на этапе компиляции
   - Шаблонных параметров
   - Размеров массивов
